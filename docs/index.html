VitrinaDos opciones

Un catálogo al día, dos caminos

Las dos opciones leen las mismas fuentes reales (Privilex, Designer Room, Clothing Girl y dos carpetas de Drive) y ordenan los productos con la misma lista de categorías. Cambia quién lo opera y hasta dónde puede crecer.

Opción 1

Catálogo con MCP

Claude mantiene el catálogo al día. Camilo solo comparte el enlace.

  1. Un servidor MCP lee las cinco fuentes cada 3 días, sin intervención.
  2. Cada producto queda en la lista común de categorías.
  3. Todo lo leído se publica en la vitrina, ordenado por categoría.
  4. Desde Claude se consulta, se busca o se pide una actualización.

Opción 2

Plataforma central

Agentes en paralelo, categoría y marca con IA, publicación automática y base para crecer.

  1. Un botón lanza un agente por proveedor, todos al mismo tiempo.
  2. Las reglas y un modelo de lenguaje completan categoría y marca.
  3. Se publica solo lo que tiene precio, foto y categoría.
  4. Camilo agrega proveedores nuevos desde la plataforma.
